# コンシェルジュを展開する

Adobe Brand Conciergeを導入すれば、実際のweb サイト訪問者が利用できるようになります。 このビデオでは、訪問者のエンゲージメントが追跡されるようにデータストリームを設定し、コンシェルジュが表示されるページとドメインを制御するようにサーフェス設定を設定する方法について説明します。

## この動画は誰のためのものでしょうか？

* web サイトにコンシェルジュを導入するマーケター
* データストリーム IDを提供し、スクリプトをインストールするITまたはweb開発チーム
* サイト全体でコンシェルジュの表示場所を制御するチーム

## ビデオコンテンツ

* Adobe Experience Platformのデータストリーム IDを検索する場所は、データ収集/データストリームの下にあります
* データストリーム設定を追加し、結果のインストールスクリプトをコピーする方法
* スクリプトのフルページのインストールオプションと比較したコンポーネントインストール
* ドメインとパスを一致させてサーフェスルールを設定する方法（任意、で始まる、で終わる、等しい）
