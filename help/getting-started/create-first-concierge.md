# 最初のコンシェルジュを作成

わずか数分で最初のAdobe Brand Conciergeを設定する方法について説明します。 web サイトのURLを入力すると、Brand Conciergeがスターターとなるブランドプロファイルと手順をサイト独自のコンテンツから自動的に構築し、保存する前に確認して調整することができます。 コンシェルジュを構築したら、デスクトップとモバイルの両方でサンプルの質問を使用してテストし、独自のサイトコンテンツを使用してどのように対応するのかを確認します。

## この動画は誰のためのものでしょうか？

* デジタルExperience Manager
* マーケティング技術者
* Adobe Customer Experience Designer

## ビデオコンテンツ

* web サイトのURLを入力することで、ブランドプロファイルとその手順を自動的に入力する方法
* 保存する前にブランドプロファイル、手順、スタータープロンプトを確認し、調整する方法
* デスクトップとモバイルでサンプルの質問を使用してコンシェルジュをテストする方法
