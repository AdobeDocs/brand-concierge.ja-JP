# 多言語対応

Adobe Brand Conciergeは、コンシェルジュを作成するときに選択した言語で対応できます。 ナレッジソースは別の言語で作成でき、回答は訪問者向けにローカライズされます。 このビデオでは、同じ英語のweb サイトから英語とフランス語のコンシェルジュを作成し、それらの回答を比較する様子を示します。

## この動画は誰のためのものでしょうか？

* 多言語コンシェルジュ体験を作成するマーケターとコンテンツ所有者
* 各地域の顧客との会話を評価するチーム
* ナレッジソースとは異なる言語で回答を提供したいユーザー

## ビデオコンテンツ

* ナレッジソースと同じweb サイトを使用して、英語とフランス語のBrand Concierge インスタンスを作成する方法
* 選択した応答言語が回答とスタータープロンプトカードに与える影響
* カタログやweb サイト URLなどのインポートされたナレッジソースがローカライズされた応答をどのようにサポートするか
