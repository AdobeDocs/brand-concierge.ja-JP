# コンシェルジュのビジュアルスタイルをカスタマイズ

Adobe Brand Conciergeの出発点となるのは、Adobeで既に用意されている視覚的な選択肢（web サイトから取得したカラーパレット、フォント、カード画像）です。 このビデオでは、これらのオプションを確認し、ウェルカムメッセージとスタータープロンプトカードをカスタマイズして、ブランドに合わせます。

## この動画は誰のためのものでしょうか？

* ブランドチームとマーケティングチーム
* コンテンツデザイナーおよびコピーライター
* コンシェルジュのデザインを微調整する人は誰でも

## ビデオコンテンツ

* Brand Conciergeがweb サイトからスターターカラー、フォント、カード画像を取得する方法
* デフォルトのデスクトップとモバイルの外観をテストする方法
* ウェルカムメッセージの見出しと小見出し（テキストカラー、太さ、サイズなど）の編集方法
* スタータープロンプトカード（カードテキスト、画像、背景色など）の追加、削除、編集の方法
