# 初めてのBrand Conciergeの構築とテスト

この記事では、コンシェルジュの作成とレビューの準備（初期設定からフィードバック用の共有まで）について説明します。

## 事前準備

最初のコンシェルジュを作成する前に、次の情報を収集してください。

- **ブランドのweb サイト URL:**&#x200B;これは、最初のコンシェルジュを作成するために必要な唯一の入力です。 Composerはそれを読み取り、他のほとんどの設定を自動的にドラフトします。
- **Brand Conciergeへのアクセスが既に許可されていることを確認します。** 「[ ユーザーとアクセス管理](../user-and-access-management/add-a-user-to-the-org.md)」を参照してください。 ログインできない場合は、ITまたは管理者のタスクで、このガイドでは解決されません。
- **商品カード情報：**&#x200B;回答の商品カードについては、AEM SitesまたはContent AI接続、または商品カタログの名前、説明、画像、リンクを含む商品のスプレッドシートを用意します。
- **Adobe Commerceの詳細：** Adobe Commerceをご利用のお客様は、コマースまたはIT チームから環境ID、ストアコード、API キーを取得します。
- **15～30分の中断のない時間：**&#x200B;設定のほとんどは、AIが生成したドラフトをレビューし、簡単に編集することを含むもので、ゼロからコンテンツをオーサリングする必要はありません。

## ステップ 1：コンシェルジュを設定し、プレビューでテストする

1. [ コンシェルジュの管理](../concierge-management/concierge-management.md)に移動し、Web サイトのURLを使用してコンシェルジュを作成します。
2. 訪問者の代表的な質問をいくつか使用して、ライブプレビューでテストします。

## ステップ 2：ブランドエクスペリエンスのカスタマイズ

1. 制作時に作成したブランド表現とブランドプロファイルを洗練させることができます。 詳しくは、[ コンシェルジュの管理](../concierge-management/concierge-management.md)を参照してください。
2. コンシェルジュの手順とガードレールを確認し、調整する。
3. ブランドの要件に合わせて、トーンやボイス、ビジュアルスタイル、チャットコンポーネントを調整できます。

## ステップ 3：評価の実行

1. [ コンシェルジュの評価](../evaluation/evaluation.md)に移動し、各評価タイプの評価セット（機能、スコープ外、およびセーフガード）を作成します。
2. 続行する前に、評価を実行し、フラグ付きの結果を確認します。

## 手順4：共有可能なプレビューリンクの作成

1. [ コンシェルジュの管理](../concierge-management/concierge-management.md)から、コンシェルジュの現在のプレビューへの共有可能なリンクを生成します。
2. Composerへのアクセス権を持たずに、関係者とフィードバック用にリンクを共有できます。

コンシェルジュをカスタマイズ、評価、レビューしたら、[ コンシェルジュのデプロイ ](../deployment/deployment.md)を参照して、実際の訪問者が利用できるようにします。次に、[公開チェックリスト ](../go-live-checklist/go-live-checklist.md)および[ コンシェルジュのパフォーマンスを分析](../analytics/analytics.md)します。
