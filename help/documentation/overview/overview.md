# Brand Conciergeの概要

Brand Conciergeは、企業やブランドが、web サイト、モバイルアプリ、その他のデジタルプロパティなど、顧客と接するサーフェスでパーソナライズされた会話体験を立ち上げることを可能にするエージェント型プラットフォームです。 あらゆるコミュニケーションは、ブランド独自のコンテンツとガードレールに基づいています。そして、それらの会話から得たインサイトは、Marketo Engageなどのブランドのエコシステム全体に反映されます。

## 主要コンポーネント

Brand Conciergeの導入には、大きく分けて次の2つの部分があります。

| 部分 | 概要 |
|---|---|
| **訪問者エクスペリエンス** | web サイトやモバイルアプリなど、訪問者がコンシェルジュと接触し、リアルタイムで回答を得るブランド向けのサーフェス。 |
| **コンポーザー** | 実務担当者のインターフェイスを使用して、コンシェルジュエクスペリエンスを設計し、コンシェルジュ、統合、設定、評価、デプロイメント、分析を管理できます。 |

## パーツの接続方法

ナレッジソース（コンテンツ）は、スキル（ビヘイビアー）と呼ばれる統合（接続）によってクエリされ、訪問者が操作するコンシェルジュ（全体的なエクスペリエンス）に包まれます。

## 用語集

これらの用語は、Composerのインターフェイス全体に表示されます。

| 用語 | 定義 |
|---|---|
| **コンシェルジュ** | AI チャット体験そのもの：ブランド、web サイト、ユースケースごとに1つ アカウントには複数のアカウントを持つことができます。 |
| **コンポーザー** | コンシェルジュの構築と管理に使用されるインターフェイス。web サイトの訪問者が目にするインターフェイスとは異なります。 |
| **ナレッジソース** | Web サイトのページや商品リストなどの質問に答える際に、コンシェルジュが使用できるコンテンツ。 1つがないと、コンシェルジュは何も答えることはできません。 |
| **統合** | Web サイトのコンテンツやライブ製品カタログなどの情報を取得できるシステムへの接続。 |
| **スキル** | 一般的な質問への回答、商品の比較、ミーティングの予約など、コンシェルジュが実行できる特定の機能。 スキルは、その機能を実行するために1つ以上の統合を使用します。 |
| **ガードレール** | 競合他社や法的アドバイスなど、コンシェルジュが行わないこと、または議論すべきことを定義するルール。 |
| **評価** | コンシェルジュサービスのパフォーマンスを評価するために使用される、予想される回答と組み合わせたサンプル質問から成る構造化テスト。 |
| **データストリーム ID** | Adobeシステム内で訪問者のアクティビティデータが送信される場所を指定する技術識別子。 IT部門または分析部門によって提供されます。 |
| **サンドボックス** | 組織内の孤立したワークスペース。 1つの組織に複数のコンシェルジュを配置することもできます。 |
| **IMS組織** | 組織全体のアカウントに対するAdobeの用語。 |
| **MCP** （例：Commerce MCP） | Adobe Adobeで管理されているコネクタで、IT部門やコマースチームが提供するコードやキーを使用して、ライブ商品カタログなどの特定のシステムに接続できます。 |
| **CJA （Customer Journey Analytics）** | Adobeの。 Brand Conciergeでは、追加の設定は不要で、スターターダッシュボードがここに自動的にプロビジョニングされます。 |

>[!NOTE]
>
>マーケターは通常、[&#x200B; ユーザーとアクセス管理](../user-and-access-management/add-a-user-to-the-org.md)を完全にスキップし（IT部門の誰かが1回のみ完了）、[&#x200B; ナレッジソース &#x200B;](../knowledge-sources/knowledge-sources.md)から開始できます。 ユーザーに戻り、新しいチームメイトを設定する場合にのみ管理にアクセスします。
