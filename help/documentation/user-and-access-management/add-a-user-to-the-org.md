# 組織へのユーザーの追加

ユーザーがBrand Conciergeにアクセスする前に、Adobe Admin ConsoleのAdobe Experience Platform組織にユーザーを追加します。

>[!PREREQUISITES]
>
>- 組織への管理者アクセス権が必要です。
>- ユーザーは、個別に追加するか、ユーザーの一括アップロードを通じて追加できる必要があります。

## ユーザーの追加

1. **Admin Console**&#x200B;に移動します。
1. **管理**&#x200B;を選択するか、**ユーザー**&#x200B;に移動します。
1. ユーザーを個別に追加することも、一括アップロードで複数のユーザーを追加することもできます。
1. ユーザーが組織にまだ存在しない場合は、プロンプトが表示されたときにユーザーを新しいユーザーとして追加するオプションを選択します。
1. 製品プロファイルを選択します。

   - **Adobe Experience Platform**
   - デフォルトのユーザープロファイル

1. 「**保存**」を選択します。

ユーザーは、組織へのアクセスを確認する招待メールを受信します。

>[!IMPORTANT]
>
>組織の招待状は、ユーザーに組織へのアクセス権を付与しますが、Brand Conciergeへのアクセス権は付与しません。 Brand Concierge アクセス権を付与するには、[Brand Concierge アクセス権を持つロールの作成](./create-a-role.md)の説明に従って、Brand Concierge アクセス権を持つロールを作成して割り当てます。

## 次の手順

ユーザーが組織に追加されたら、**Brand Conciergeの管理**&#x200B;権限を持つロールを作成し、そのロールにユーザーを割り当てます。
