# Brand Concierge ロールへのユーザーの追加

**Brand Conciergeの管理**&#x200B;権限を含むロールにユーザーを割り当てます。 また、Brand Conciergeを使用する前に、Adobe Experience Platform組織にアクセスできる必要があります。

## 前提条件

* ユーザーがAdobe Experience Platform組織に追加されました。 詳しくは、「組織へのユーザーの追加」（LINK）を参照してください。
* **Brand Conciergeの管理**&#x200B;権限を含むロールが作成されました。 詳しくは、「Brand Concierge権限を持つロールの作成」（LINK）を参照してください。

## 役割からのユーザーの追加

1. Adobe Experience Platformで、**権限**&#x200B;を開きます。
2. Brand Concierge アクセス用に作成されたロールを開きます。
3. 「**ユーザー**」タブを選択します。
4. ユーザーを検索し、そのユーザーを役割に追加します。
5. プロンプトが表示されたら、割り当てを保存します。

## ユーザーレコードからの役割の追加

ユーザーのレコードから役割を割り当てることもできます。

1. ユーザーのレコードを開きます。
2. 「**役割を追加**」を選択します。
3. Brand Concierge ロールを検索します。
4. 役割を選択し、割り当てを保存します。

## アクセスを確認

組織の招待と役割の割り当ての両方が完了すると、ユーザーは次のことが可能になります。

* `experienceplatform.adobe.com`にログインします。
* アクセスできる組織を表示します。
* **Brand Concierge**&#x200B;を開きます。
* 役割を通じて付与されたサンドボックスを表示します。

サンドボックス内で、複数のコンシェルジュを作成することができます。
