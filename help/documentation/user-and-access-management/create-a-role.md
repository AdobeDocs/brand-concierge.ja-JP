# Brand Concierge権限を持つロールの作成

Adobe Experience Platform権限でロールを作成して、ユーザーにBrand Conciergeへのアクセス権を付与します。

## 前提条件

* 役割と権限を管理するために必要な管理者権限が必要です。
* 最初にAdobe Experience Platform組織にユーザーを追加する必要があります。 詳しくは、「組織へのユーザーの追加」（LINK）を参照してください。

## 役割の作成

1. `experienceplatform.adobe.com`にログインします。

   >[!NOTE]
   >
   >この手順を公開する前に、エンジニアリングで実稼動URLを確認します。 ソースの記録に非公式な、あるいは文字起こしされていない可能性のあるURLが使用されていました。

2. 左側のナビゲーションで、**権限**&#x200B;までスクロールして選択します。
3. **役割**&#x200B;を選択して既存の役割を表示し、**新しい役割を作成**&#x200B;を選択します。
4. 役割の名前（`Brand Concierge Access Users`など）を入力し、説明を追加して、作成を確認します。
5. 新しい役割を開き、権限を割り当てます。

   1. **Brand Concierge**&#x200B;の権限リストを検索します。
   2. 「**Brand Conciergeを管理**」を選択します。

   現在、**Brand Conciergeの管理**&#x200B;は、利用可能なBrand Concierge権限の中で唯一のものです。 詳細な権限層は現在利用できません。

6. 役割がアクセスできるサンドボックスを選択します。

   組織には、独立したワークスペースである複数のサンドボックスを含めることができます。 この役割に適したサンドボックスのみを選択します。

7. 「**保存**」を選択します。

## 次の手順

役割を作成したら、その役割にユーザーを追加します。 詳しくは、「役割にユーザーを追加」（LINK）を参照してください。

## 関連する検討事項

* サンドボックスの作成と管理のプロセスは、この手順の範囲外です。
* 長期的なロールモデルを定義する前に、Brand Conciergeの詳細な権限を追加する予定があるかどうかを確認します。
