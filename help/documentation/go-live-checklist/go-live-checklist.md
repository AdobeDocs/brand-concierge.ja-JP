# コンシェルジュ向け公開チェックリスト

実際の訪問者がコンシェルジュを利用できるようにする前に、このチェックリストを使用してローンチ前の準備状況レビューを完了します。 チェックリストでは、ナレッジソース、コンシェルジュ管理、評価、デプロイメントワークフローに記載されている準備基準が統合されます。

>[!NOTE]
>
>このチェックリストを独立したページとして公開することを検討してください。 スタンドアロンページは、ローンチコミュニケーションから直接リンクでき、完全なドキュメントセットとは関係なく参照できます。

## このチェックリストの活用方法

ローンチの前に各項目を完了し、フォローアップが必要な項目の所有者または証拠を記録します。 適切な製品、品質、ローンチの所有者がリスクを確認し、受け入れない限り、未解決の問題を抱えて本番稼動に進まないでください。

## コンテンツと設定

- [ ] **ナレッジソースは完全に処理されています。** すべての設定済みナレッジソースの処理が完了し、未解決のエラーが&#x200B;**問題の修正**&#x200B;に残っていないことを確認します。
- [ ] **ブランド表現とブランドプロファイルが正確です。** コンシェルジュのブランド表現とブランドプロファイルを確認し、意図した体験との正確さと整合性を確認します。
- [ ] **手順とガードレールが承認されました。** 該当するブランドガイドラインに照らし合わせて、コンシェルジュの手順とガードレールを確認します。
- [ ] **スキルと統合が正しくマッピングされています。** 必要なすべてのスキルが有効化され、その統合に正しくマッピングされていることを確認します。
- [ ] **ビジュアルスタイルとチャットコンポーネントが承認されました。** ブランドの期待に合わせて、ビジュアルスタイルとチャットコンポーネントを確認しましょう。

## 検証と評価

- [ ] **評価セットが作成され、実行されました。** 評価タイプごとに少なくとも1つの評価セットを作成して実行します。
  - 機能的
  - 範囲外
  - セーフガード
- [ ] **フラグ付きの結果がレビューされました。** ローンチ前に、フラグ付きの評価結果を調査し、対処します。
- [ ] **ライブプレビューテストが完了しました。** 訪問者の代表的な質問を使用して、ライブプレビューでコンシェルジュをテストします。

## デプロイの準備状況

- [ ] **データストリーム IDが設定されています。** デプロイメント用に正しいデータストリーム IDが設定されていることを確認します。
- [ ] **サーフェス設定がレビューされました。** コンシェルジュが目的のページにのみ表示されることを確認します。
- [ ] **インストールスクリプトがインストールされています。** インストールスクリプトをweb サイトチームに提供し、インストールが正常に完了したことを確認します。
- [ ] **B2Bの可用性が確認されました（該当する場合）。** B2B コンシェルジュの場合は、営業担当者のカレンダーとライブチャットの可用性が設定され、運用可能であることを確認します。

## ローンチ後の対応

- [ ] **Analyticsへのアクセスが確認されました。** 関係者が必要な分析にアクセスできることを確認します。
- [ ] **レビューの頻度が確立されました。** 会話の文字起こしを確認し、新しい評価クエリを追加するための定期的なプロセスを確立します。

## このチェックリストをリリース要件として公開する前

>[!IMPORTANT]
>
>このチェックリストは、ガイドに記載されているワークフローから導き出されます。 これは、製品定義の正式なリリースゲートではありません。 正式な公開要件として公開する前に、製品およびQA定義のリリース基準に照らして検証します。
