# 技術的な設定とオプション機能

Adobe Adobe Brand Conciergeに対応したweb サイトを構築し、訪問者の体験をサポートするオプション機能を導入しましょう。 このビデオでは、デプロイメントの要件、コンシェルジュをサイトに追加する方法、ミーティング予約、ライブチャット、Marketo Engageの統合機能について説明します。

## この動画は誰のためのものでしょうか？

* web サイトの開発者および管理者
* マーテク部門

## ビデオコンテンツ

* デプロイメント要件：タグ管理システムまたは手動で追加されたコードスニペット、ターゲットページ、Adobe Experience Platform サンドボックスおよびIMSのオーガナイゼーション、データストリーム
* タグマネージャーを使用するか、コードベースから直接web サイトにコンシェルジュを追加する
* 担当者、空き状況、スケジュールの詳細を含むミーティング予約の設定
* 担当者の空き状況、訪問者のトリガー、ミーティング予約のフォールバックを利用したライブチャットの実現
* 管理者アクセス権と機能フラグを使用して、Marketo Engageを接続してリードとアクティビティを受け取る
